# 專欄文章寫作指南

把 Markdown 檔案放進這個資料夾（`content/columns/`），網站就會自動出現一篇新專欄。

## 怎麼新增一篇文章

1. 在這個資料夾建立一個 `.md` 檔，檔名就是網址（slug）。
   - 例如 `my-first-article.md` → 網址是 `/columns/my-first-article`
   - 檔名建議用英文或拼音、小寫、用 `-` 連字，不要有空格或中文
2. 檔案最上方要有 frontmatter（下方 `---` 中間那段），填好標題、日期等資訊
3. 底下就用一般 Markdown 寫內容
4. 存檔後 `git add . && git commit -m "新增專欄" && git push`，網站幾分鐘後自動更新

## Frontmatter 格式（每篇必填）

```markdown
---
title: 文章標題
date: 2026-07-01          # 發布日期，格式 YYYY-MM-DD，列表會依此由新到舊排序
excerpt: 一兩句話的摘要，會顯示在文章列表上。
tags: ["AI 導入", "教學"]   # 標籤，可放一到多個
author: 陳孟宏             # 可省略，預設就是「陳孟宏」
---

這裡開始寫正文……
```

## 常用 Markdown 語法

```markdown
## 大標題
### 小標題

一般段落文字。**粗體**、*斜體*。

- 項目一
- 項目二

1. 有序清單
2. 第二點

> 引用區塊，適合放金句。

[連結文字](https://example.com)

![圖片說明](圖片網址)
```

排版樣式（字級、行距、顏色）都已經設定好，你只要專心寫內容即可。
